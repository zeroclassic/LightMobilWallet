⚠️ Notes

This is a light wallet — no blockchain sync required.

Private keys are stored locally and never sent to any server.

Always keep a secure backup of your private key (WIF).

Works only with transparent ZERC t-addresses for now (t1...).

🛠 Technical

RPC configuration remains identical:

RPC: http://<your-zercd-node>:4488
User: rpcuserdcazerc
Pass: rpcpassdcazerc


Compatible with getaddressbalance, getaddressutxos, signrawtransaction, sendrawtransaction.
