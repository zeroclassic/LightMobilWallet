🚀 ZercWallet Mobile v1.6.5 — New Release!


We’re excited to announce the release of ZercWallet Mobile v1.6.5 🎉
This update introduces a highly requested feature and further improves the experience for all $ZERC holders using the mobile light wallet.


🔐 What’s new in v1.6.5?


🔑 Private Key Import (NEW)

Easily import an existing ZERC t-address using its private key (WIF).
Perfect for restoring a wallet or migrating funds without generating a new address.

📸 QR Code Scanner

Quickly scan ZERC addresses when sending funds — no manual typing needed.

🔄 Auto Balance Refresh

Your balance now updates automatically every 30 seconds.

🧮 Improved Send UI

Clearer display of available balance and automatic MAX fill (minus network fee).

🏷️ Enhanced TX History

Faster loading and cleaner transaction formatting.

🎨 UI Enhancements

Improved layout, better visual consistency, and smoother navigation.

🔒 PIN Protection

Wallet remains secured with encrypted private keys + 4-digit PIN.

⚠️ Important Notes

This is a light wallet — no blockchain sync required
Private keys are stored locally and never sent to any server
Always keep a secure backup of your private key (WIF)
Currently supports transparent ZERC addresses only (t1...)
